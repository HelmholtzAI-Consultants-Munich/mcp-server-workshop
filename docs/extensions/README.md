# Optional extensions

The tracks below are **optional extensions**. Everyone first completes the two
core tasks: your own MCP server, then the adapter that connects it to the model.
Pick a track only once both work, and only one.

Start with the [main README](../../README.md).

## Track A — Feature sprint

Open [Track A — Feature sprint](track-a-feature-sprint.md). Pick a task, implement it, and fill
in the deliverable section at the bottom of the same file.

## Track B — Architecture planning

**No coding.** Open [Track B — Architecture planning](track-b-architecture-planning.md). Plan
integration of this workshop’s MCP + phased pipeline into your project or
another project you choose. Fill in the same file.

## Track C — Integration experiments

Open [Track C — Integration experiments](track-c-integration-experiments.md). Five phases (~60
min): baseline demo → your queries → compare tools vs bot → failure analysis →
optional small fix. **No API key** for most phases.

Easiest to **start**, not necessarily shortest if done fully.

## Setup

See the README. Please arrive with the repository cloned and the environment
working; no API key is needed in advance.
